Aleka — это лёгкое, быстрое приложение для рисования, написанное на Flutter. Оно работает везде: в браузере, на десктопе (Windows, macOS, Linux) и на мобильных устройствах (iOS, Android).

Под капотом — чистый Dart, Material 3 и внимание к деталям.

<h2>Возможности</h2>

<ul>
<li><b>Рисование от руки:</b> плавные штрихи с квадратичной интерполяцией Безье.</li>
<li><b>Палитра из 15 цветов:</b> быстрый выбор с визуальной индикацией.</li>
<li><b>Размер кисти:</b> регулируется слайдером от 1 до 30 px.</li>
<li><b>Отмена (Undo):</b> шаг назад по вашим штрихам.</li>
<li><b>Очистка холста:</b> одним нажатием.</li>
<li><b>Заливка (Flood Fill):</b> BFS с tolerance для сглаженных краёв.</li>
<li><b>Сохранение:</b> формат <code>.aleka</code> (JSON).</li>
<li><b>Загрузка:</b> открывайте ранее сохранённые рисунки и продолжайте.</li>
<li><b>Экспорт PNG:</b> захват холста в 3x разрешении.</li>
<li><b>🎬 Режим анимации:</b> покадровая анимация с временной шкалой:
  <ul>
    <li>Добавление и удаление кадров, каждый со своим рисунком.</li>
    <li>Длительность кадра от 50 мс до 5 с.</li>
    <li>Смена FPS: 6, 8, 12, 15, 24, 30 или 60.</li>
    <li>Экспорт в MP4 (через ffmpeg на десктопе, ffmpeg.wasm в браузере).</li>
  </ul>
</li>
<li><b>Тёмная и светлая тема:</b> Material 3, следует за системой.</li>
</ul>

<h2>Почему Flutter?</h2>

Flutter позволяет писать одно приложение для шести платформ без дублирования кода. Aleka использует только нативные возможности Dart и Flutter SDK и минимум сторонних зависимостей: <code>file_picker</code>, <code>image</code> для работы с пикселями при заливке, <code>ffmpeg_wasm</code> для экспорта видео в браузере.

<h2>Архитектура</h2>

Проект придерживается принципов чистой архитектуры и SOLID:

<ul>
<li><b>PaintCanvasController</b> — управляет состоянием штрихов и заливки через паттерн Listener/Observer.</li>
<li><b>PaintToolbar</b> — UI-компонент палитры, ползунка и кнопок.</li>
<li><b>AlekaFile</b> — сериализация/десериализация в JSON, захват PNG.</li>
<li><b>MovieController</b> — модель кадров и состояния анимации.</li>
<li><b>VideoExport</b> — инкапсулирует логику кодирования MP4 (десктоп/веб).</li>
</ul>

Функции ввода-вывода (<code>saveStrokes</code>, <code>loadStrokes</code>, <code>capturePng</code> и др.) сделаны injectable — их можно заменять на моки при тестировании. В проекте 79 тестов: проверка сериализации, отмены, загрузки/сохранения, экспорта PNG и видео, модели кадров и временной шкалы.

<h2>Формат файла .aleka</h2>

Файл <code>.aleka</code> — это читаемый JSON, который можно открыть в любом текстовом редакторе:

<pre><code>{
  "aleka": "1.0",
  "strokes": [
    {
      "color": 4278190080,
      "strokeWidth": 3.0,
      "points": [[100.0, 200.0], [150.0, 250.0]]
    }
  ]
}
</code></pre>

Каждый штрих хранит цвет (ARGB32), толщину и массив точек. Формат версионирован полем <code>aleka</code>.

<h2>Режим анимации</h2>

Одна из ключевых фич — встроенный редактор покадровой анимации. Вы рисуете кадр, добавляете новый, рисуете следующий — и так далее. Временная шкала показывает миниатюры, позволяет менять порядок и длительность кадров. Готовую анимацию можно экспортировать в MP4.

Алгоритм экспорта перебирает все кадры, захватывает их через <code>RepaintBoundary</code>, собирает PNG-байты и передаёт в энкодер. На десктопе вызывается системный ffmpeg, в браузере используется ffmpeg.wasm — полноценный порт ffmpeg в WebAssembly, работающий прямо в песочнице браузера.

<h2>Заливка (Flood Fill)</h2>

Реализация заливки использует поиск в ширину (BFS) с допуском по цвету (<code>_kFillTolerance = 1000</code>). Это позволяет корректно обрабатывать сглаженные края штрихов — заливка не вытекает за контур, но захватывает полупрозрачные пиксели на границе. Для пустого холста создаётся сплошная заливка без лишних вычислений.
