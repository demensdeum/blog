Title: Mama Calendar — кроссплатформенное приложение для напоминаний
Slug: mama-calendar
Categories: software

Mama Calendar — это кроссплатформенное приложение для событий и напоминаний, написанное на React Native (Expo) с двумя реализациями бэкенда: Node.js + MongoDB и PHP + MariaDB.

Приложение позволяет создавать события с эмодзи-категоризацией, выбирать тип повторения (однократно, ежегодно, ежемесячно, еженедельно, ежедневно) и просматривать важные события на ближайшие 3 дня на отдельной вкладке "Important Events".

<h2>Стек технологий</h2>
Фронтенд написан на React Native 0.86 через Expo SDK 57 с TypeScript, Expo Router для навигации и <code>react-native-reanimated</code> для анимаций. Для иконок используется expo-symbols (SF Symbols на iOS, Material иконки на Android/Web).

Бэкенд реализован в двух вариантах:
<ul>
<li><b>Node.js:</b> Express 4, MongoDB 8 через нативный драйвер, самописная аутентификация с scrypt + salt, ручное управление токенами. Docker Compose поднимает клиент (nginx), сервер и MongoDB.</li>
<li><b>PHP:</b> PHP 8.2 без фреймворков, PDO + MariaDB 11, bcrypt для хеширования паролей, свой роутер и PSR-4 автолоадинг через Composer.</li>
</ul>

<h2>Функции приложения</h2>
<ul>
<li><b>Регистрация и авторизация:</b> простая система с username/password и Bearer-токенами</li>
<li><b>CRUD событий:</b> создание, просмотр, редактирование и удаление событий с датой, эмодзи и типом повторения</li>
<li><b>Умная фильтрация:</b> вкладка Important Events показывает события на ближайшие 3 дня с учетом правил повторения. Например, ежегодные события показывают ближайшее годовое вхождение, ежемесячные — по дню месяца, еженедельные — по дню недели</li>
<li><b>Эмодзи-пикер:</b> 20 предустановленных эмодзи для быстрой категоризации событий</li>
<li><b>Подсветка сегодняшних событий:</b> события на сегодня выделяются красным фоном (#B71C1C)</li>
<li><b>Тёмная тема:</b> автоматическое определение системной цветовой схемы с отдельными палитрами для светлой и тёмной темы</li>
<li><b>Интернационализация:</b> русский и английский языки через React Context</li>
<li><b>Анимации:</b> анимированный сплэш-скрин с Keyframe API и упругой интерполяцией, анимированная иконка приложения с вращающимся свечением</li>
<li><b>Админ-эндпоинты:</b> управление пользователями, токенами и очистка базы через мастер-токены</li>
</ul>

<h2>Почему две реализации бэкенда?</h2>
Node.js версия является основной, но PHP вариант существует как альтернатива для более классического хостинга. API полностью идентичен, что позволяет переключаться между ними без изменения клиентского кода.

<h2>Инфраструктура</h2>
Весь стек поднимается через Docker Compose: клиент собирается через мультистейдж билд (Expo export → nginx alpine), сервер на Node.js, MongoDB 8. Для PHP-версии есть отдельный compose-файл с MariaDB 11 и phpunit для тестов.

Сборка веб-версии автоматизирована PowerShell-скриптом, который патчит API_URL перед <code>expo export</code> и восстанавливает оригиналы после.

<h2>Вывод</h2>
Mama Calendar — это полнофункциональное кроссплатформенное приложение, которое покрывает полный цикл: от мобильного и веб-фронтенда на React Native до двух вариантов серверной части. Проект интересен своей архитектурой, использованием современных возможностей Expo SDK и двойной реализацией бэкенда.
